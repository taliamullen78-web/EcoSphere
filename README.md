# EcoSphere

A lightweight static site for exploring sustainability labels and more considered choices.

Pages:
- `index.html` — brand finder
- `analyzer.html` — illustrative product analyzer
- `eco-map.html` — sample eco-map
- `game.html` — sustainability-label quiz and arrow-key label-catching game
- `sources.html` — educational references and media credits

Open `index.html` in a browser to explore the site. Some external assets, including map tiles and typefaces, require an internet connection.
